# 套利机会扫描器 📊

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](arb_scan.py)
[![Deps](https://img.shields.io/badge/依赖-零依赖-brightgreen.svg)](#运行)
[![API Key](https://img.shields.io/badge/API%20Key-不需要-orange.svg)](#风险提示必读)

只监控、不下单、不碰你的 API key 和资金。帮你发现两类搬砖套利机会，执行靠你自己手动操作。

> ⚠️ **先看结论**：2026-10-18 实测，OKX 过去 30 天 16 个主流币里，只有 TRX 年化 14.7% 过 10% 线（且 30 天翻转 20 次）；BTC 4.5%、ETH 3.7%、SOL 4.0%，其余 4–7%——扣掉手续费基本白干。**当前市场资金费率套利不值得动手**，这个工具就是帮你算清这笔账的。

## 功能

1. **资金费率套利扫描**（`arb_scan.py`）：扫描 OKX 永续合约资金费率，按年化排序。
费率为正 → 现货买入 + 合约做空（收资金费）；费率为负 → 反向。
2. **跨所现货价差**（`arb_scan.py`）：Binance vs OKX 现货价差，价差 >0.3% 才值得看。
3. **资金费率回测**（`funding_backtest.py`）：`arb_scan.py` 告诉你"现在"费率多少；这个告诉你"过去 N 天这策略到底赚不赚钱"，专治"看到 -800% 年化就想冲"的冲动。

## 运行

```bash
python3 arb_scan.py # 跑一次
python3 arb_scan.py --watch 300 # 每 5 分钟循环
python3 arb_scan.py --min-apy 30 # 只看年化 >=30% 的
python3 arb_scan.py --coins BTC,ETH,SOL # 指定币种
```

```bash
python3 funding_backtest.py # 过去 30 天，主流币
python3 funding_backtest.py --days 90 # 回测 90 天
python3 funding_backtest.py --coins BTC,ETH,SOL
python3 funding_backtest.py --min-apy 10 # 只看年化 >=10% 的
```

零依赖，只用 Python 标准库。不需要 API key，只读公开行情接口。

## 🚫 做不到什么

- **不做自动交易**：本工具只读公开行情，不下单、不需要你的 API key、不碰资金。
- **不预测未来**：回测是历史数据，不代表未来收益；费率每 8 小时结算一次，随时翻转。
- **不管税务和合规**：套利收益的税务申报请咨询专业人士。

## ⚠️ 常见问题

**Q: 扫描显示年化 -800%，可以直接冲吗？**
A: 不行。先用 `funding_backtest.py` 看这个币过去 30 天的费率翻转次数。超高年化通常几小时就回归，翻转 20+ 次的币持仓体验极差。

**Q: 为什么跨所价差总是 <0.1%？**
A: 正常。成熟市场价差平时就是 0.0x%，0.3% 阈值是扣掉双边手续费后的经验线。指望发现价差再转账的，转账到价差就没了——必须两边预存资金同时对冲下单。

**Q: 支持 Bybit / Binance 合约吗？**
A: 暂不支持。Bybit 在当前网络环境被地域限制，Binance 合约接口返回 451。OKX 公开接口全通。

**Q: 需要注册 API key 吗？**
A: 不需要。两个工具都只读公开行情，不下单。任何让你填 key 的"套利工具"都要警惕。

## 风险提示（必读）

- **不是无风险**：合约端有爆仓风险（极端行情对冲会穿仓）、资金费率每 8 小时变一次、
看到的超高年化（如 -800%）通常几小时就回归，别当固定收益。
- **手续费**：一开一平约 0.1%，年化低于 10% 基本不值得做；小资金更要算清楚。
- **跨所搬砖**：价差平时只有 0.0x%，必须两边预存资金同时对冲下单；
指望发现价差再转账的，转账到价差就没了。
- **本工具不是投资建议**：所有输出仅供学习研究，下单前自己评估，出借自负。
- 本工具不做自动交易，不碰你的 API key 和资金。
